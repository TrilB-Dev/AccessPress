# AccessPress User Management

This core capability replaces the default WordPress backend user profile flow with a frontend account experience.

## Features
- frontend login
- public registration
- profile editing
- backend profile redirect
- shortcode-based forms for login, registration, and account management

## Shortcodes
- `[accesspress_login]`
- `[accesspress_register]`
- `[accesspress_profile]`

## Core integration
The user-management system is initialized as part of the AccessPress core bootstrap, not as a discoverable plugin extension.
